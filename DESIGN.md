# Portfolio design

| Role | Color |
| --- | --- |
| Canvas | Warm Cream Beige, #E8D2B5 |
| Text, links, and primary actions | Deep Burgundy, #590907 |
| Photography surface | Muted Sage Grey, #A5A79B |

Fraunces gives headings a distinct editorial voice. DM Sans supports navigation, project descriptions, and practical UI. Use generous margins, hairline rules, and project screenshots. Photography gets one homepage feature after the engineering work and writing.
